SELECTED MESSAGES

How does selection work?
  1. Keep all messages you mark important, if they fit.
  2. Try remaining messages from newest to oldest; skip any that do not fit.
  3. Restore conversation order before displaying the selected context.

If important messages exceed the budget, pause the reply rather than silently drop one.

Inclusion gives a model access to information. It does not guarantee that a real model will follow it.
